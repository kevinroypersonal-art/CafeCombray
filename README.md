# Café Combray

Landing page du Café Combray, café librairie de littérature française, 3 rue de Moscou, 75008 Paris.

Site statique (HTML, CSS, JS), sans étape de build.

- **Aperçu local** : `python3 -m http.server 4173` puis http://localhost:4173
- **Contenus modifiables** (date d'ouverture, horaires, carte, Instagram, e-mail) : `config.js`
